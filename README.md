# MyBlog Portfolio

Este projeto é uma aplicação web desenvolvida em Python e Flask, baseada nos conceitos avançados do livro *"The Well-Grounded Python Developer"*.

## 🚀 Tecnologias e Padrões Aplicados (Capítulo 7)

Nesta etapa, foquei na estruturação profissional da aplicação:

- **Application Factory Pattern:** Implementação de `create_app()` para melhor gerenciamento do ciclo de vida da aplicação.
- **Flask Blueprints:** Organização modular do código em namespaces (ex: `intro_bp`).
- **Bootstrap 5 & Design Responsivo:** Interface moderna com uso de Media Queries para adaptação em dispositivos móveis.
- **Ambiente Isolado:** Uso de `venv` e `requirements.txt` para garantir a portabilidade do projeto.

## 🛠️ Como rodar o projeto

1. Clone o repositório: `git clone https://github.com/LeinadAyla/my-blog-portfolio.git`
2. Crie o ambiente virtual: `python3 -m venv venv`
3. Ative o venv: `source venv/bin/activate`
4. Instale as dependências: `pip install -r requirements.txt`
5. Execute: `flask run`
